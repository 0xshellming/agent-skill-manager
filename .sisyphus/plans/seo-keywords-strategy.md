## Programmatic SEO Targets

### Comparison Pages
- `{skill1} vs {skill2}`
- Pattern: `/compare/{skill1}-vs-{skill2}`
- Example: "pdf vs docx AI skill comparison"

### Alternative Pages
- `{competitor} alternatives`
- Pattern: `/alternatives/{tool}`
- Example: "smithery alternatives"

### Category + Platform
- `{category} skills for {platform}`
- Example: "document processing skills for Claude"

## SEO Content Guidelines

### Title Tag Format
```
{Skill Name} - AI Agent Skill | agent-skill.dev
```
Max: 60 characters

### Meta Description Format
```
{Description of skill}. Compatible with Claude, OpenAI Codex. Install: askm install {author}/{skill}
```
Max: 155 characters

### H1 Format
```
{Skill Name}
```

### Schema.org Type
```
SoftwareApplication
```

## Internal Linking Strategy

1. **Skill → Category**: Every skill links to its category page
2. **Skill → Related Skills**: 4 related skills at bottom
3. **Category → Skills**: Category page lists all skills
4. **Homepage → Featured**: Top skills by stars
5. **Author → Skills**: Author page lists their skills

## URL Structure

```
/                           # Homepage
/{locale}/                  # Localized homepage
/{locale}/skills            # All skills list
/{locale}/skill/{slug}      # Skill detail
/{locale}/category/{cat}    # Category page
/{locale}/author/{author}   # Author page
/{locale}/compare/{a}-vs-{b} # Comparison page
```
